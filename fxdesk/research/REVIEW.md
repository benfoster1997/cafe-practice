# Independent code review, 11 November 2026

Three reviewers, each given a different lens and told to find what would make the backtest lie, examined the rules, the simulator and the test plan after the rulebook was committed and before any sealed data could be opened. They were barred from touching prices dated 2021 or later. 27 findings, 2 rated high; every one was confirmed by the reviewer with a script or exact reasoning. None rescues the result: after the fixes, calibration was run again and still nothing is eligible.

The first calibration had already been run when the review reported, so each fix was held to one rule: make the code do what the committed rulebook says, and do not compute how the alternative would have performed before choosing.
